Windows의 폴더와 드라이브 구조에 분할 창, 탭, 파일 정리 도구를 더했습니다.

Windows 설치 파일 받기

설치와 실행

  1. Windows 10·11 x64용 EXE를 받습니다. ZIP을 받은 경우 먼저 압축을 풉니다.
  2. 설치 프로그램을 실행하고 설치 위치를 선택합니다.
  3. 바탕 화면 또는 시작 메뉴의 FileDesk 바로가기로 실행합니다. 삭제는 Windows 설정의 설치된 앱에서 할 수 있습니다.

현재 Windows 설치 파일에는 Authenticode 개발자 서명이 없습니다. 실행 시 Windows 보안 안내가 표시될 수 있습니다. 공식 다운로드 주소와 함께 제공한 SHA-256을 확인하세요.

홈, 기본 폴더, 내 PC

왼쪽 홈에서 자주 쓰는 폴더를 모아 봅니다. 빠른 액세스에는 바탕 화면·문서·다운로드·사진·음악·동영상이 있습니다. Windows에 등록된 실제 폴더를 사용하므로 문서나 바탕 화면을 OneDrive 또는 다른 드라이브로 옮겼다면 그 위치를 엽니다.

내 PC에는 Windows (C:), 데이터 (D:), 외장 SSD (E:)처럼 볼륨 이름과 드라이브 문자가 표시됩니다. 이름과 문자는 각 PC의 설정에 따라 다릅니다. 드라이브별 남은 공간과 전체 용량을 확인할 수 있고, USB 장치 연결·해제 시 목록을 갱신합니다. 내장 드라이브와 시스템 드라이브에는 꺼내기 버튼을 표시하지 않습니다.

Windows에 맞춘 창

오른쪽 위의 기본 최소화·최대화·닫기 버튼을 사용합니다. 설정에서는 Windows 탐색기 스타일과 FileDesk 스타일을 선택할 수 있습니다. AirDrop과 Finder 태그 연동 같은 Mac 전용 메뉴는 Windows 버전에 포함하지 않습니다.

분할 창과 탭

레이아웃에서 7가지 배치와 최대 6개 창을 선택합니다. 창 사이 구분선을 드래그하면 크기가 바뀝니다. 각 창의 이동 손잡이를 드래그해 순서를 바꾸고, 손잡이를 우클릭해 창을 닫을 수 있습니다. 돋보기 옆 + 또는 Ctrl+T로 현재 창에 탭을 추가합니다.

경로의 폴더 이름을 누르면 해당 위치로 이동합니다. Ctrl+L을 누르면 경로를 직접 입력할 수 있습니다. 뒤로·앞으로는 Alt+←·Alt+→, 상위 폴더는 Alt+↑입니다.

복사, 이동, 이름 변경

Ctrl+C·Ctrl+X·Ctrl+V로 파일을 복사하거나 이동합니다. Windows 탐색기와 파일 클립보드를 함께 사용할 수 있습니다. 같은 이름의 파일이 있으면 대치·둘 다 유지·건너뛰기·취소 중에서 선택합니다. Ctrl+Z는 마지막으로 완료된 지원 파일 작업을 되돌립니다. 작업 후 수정된 파일은 보호를 위해 자동으로 되돌리지 않습니다.

F2로 이름을 변경하고, 여러 파일을 선택하면 찾기·바꾸기·정규식·접두어·접미어·번호를 미리 보며 적용합니다. Delete는 확인 후 휴지통으로 이동합니다. 우클릭에서 Windows 속성, 연결 프로그램, 바로가기 만들기와 탐색기에서 보기도 사용할 수 있습니다.

파일을 잠시 모으는 임시보관함

설정에서 FileDesk 스타일을 선택하면 하단 임시보관함을 사용합니다. 여러 폴더의 파일을 드래그하거나 클립보드에서 추가하고, 원하는 폴더에 복사하세요. 폴더는 보관하지 않습니다. 목록은 앱을 다시 열어도 유지되며, 보관 목록 지우기는 원본을 삭제하지 않습니다. 원본 파일을 이동하거나 지우면 해당 보관 항목을 사용할 수 없을 수 있습니다.

미리보기, 정렬과 꾸미기

아이콘·목록·열·갤러리 보기를 제공합니다. 선택한 파일은 미리보기로 확인하고, 지원되는 동영상과 음악은 재생 버튼으로 앱 안에서 재생합니다. 썸네일과 코덱 지원은 Windows 환경과 파일 형식에 따라 다릅니다.

이름·크기·수정일·종류로 정렬하고, 폴더 먼저 표시 여부를 선택합니다. 이름 검색은 여러 검색어와 !제외어를 지원합니다. 테마·다크 모드·사용자 지정 색상, 폴더 색상과 중앙 이미지 장식도 설정할 수 있습니다. Windows의 태그와 폴더 장식은 FileDesk 안에서 보관하며 Explorer 태그·폴더 아이콘과 동기화되지 않습니다.

서버, 클라우드와 Taildrop

왼쪽 서버 연결에서 FTP·FTPS·SFTP 계정을 등록합니다. SFTP 첫 연결에서는 서버 관리자가 제공한 호스트 키 지문을 확인하세요. SMB는 Windows에서 접근 권한이 있는 UNC 경로로 엽니다.

Google Drive·OneDrive·pCloud·Dropbox는 브라우저 로그인과 권한 동의 후 연결합니다. 계정·서버의 파일은 현재 선택한 분할 창에 표시되고, 폴더 탐색·파일 업로드·다운로드를 할 수 있습니다. 연결 정보는 PC에 암호화해 보관합니다. 서비스가 권한을 철회하면 다시 로그인해야 합니다. Google 공개 검증은 아직 완료되지 않았습니다.

Taildrop을 사용하려면 두 기기에 Tailscale을 설치해 로그인하고 연결하세요. 파일을 선택한 뒤 Taildrop에서 받을 기기를 선택합니다. 폴더는 ZIP으로 압축한 뒤 보냅니다.

공유 서버는 선택한 폴더를 FTP·SFTP로 제공합니다. 기본은 같은 PC에서만 접속 가능하며, 네트워크 연결과 업로드는 각각 선택합니다. 외부 인터넷 접속에는 라우터·Windows 방화벽 설정이 필요합니다. 암호화가 필요한 전송에는 SFTP를 사용하세요.

추가 도구와 지원 범위

ZIP 생성과 ZIP·TAR·TAR.GZ 압축 해제, 중복 파일 검색, 텍스트 문서 비교를 지원합니다. 기존 CP949 방식의 일부 한글 ZIP에는 별도 압축 도구가 필요할 수 있습니다. Mac 버전의 모든 기능이 Windows에 동일하게 구현된 것은 아닙니다.
