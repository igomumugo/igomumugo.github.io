파일 작업을 한곳에

04 / 임시보관함

파일을 잠시 모아 두세요

여러 폴더의 파일을 한곳에 모아 원하는 폴더로 복사합니다. 보관 목록을 비워도 원본은 그대로입니다.

07 / 연결

클라우드도 같은 창에서

기능별 사용 방법과 연결 조건은 사용 설명서에서 확인하세요.

일반판 1.19 · 지금 사용 가능

일반판 1.19의 새로운 편의기능과 주요 도구

탐색부터 동기화·검색·정리까지, 아래 기능은 지금 내려받는 일반판 1.19에 포함됩니다.

도구막대를 직접 꾸미기

버튼을 드래그해 순서를 바꾸고 파일·폴더·앱을 도구막대에 드롭해 바로가기로 등록합니다. 우클릭으로 표시 이름을 바꾸거나 제거하며, 원본은 변경하지 않습니다.

폴더도 임시 보관함에

파일뿐 아니라 폴더도 드래그·붙여넣기로 보관하고 현재 폴더에 복사합니다. 보관 목록에서 제거해도 원본 폴더와 내부 파일은 유지됩니다.

더 가벼운 미리보기

아이콘을 표시 크기에 맞춰 보관하고 썸네일 캐시 한도를 96MiB에서 48MiB로 줄였습니다. 메모리 부족 시 캐시와 숨겨진 미리보기를 해제합니다. 전체 점유율은 작업에 따라 달라집니다.

탐색과 선택의 흐름 유지

두 창을 연동해 탐색하고 탭을 고정·복원합니다. 스페이스 미리보기에서 ⌘⌫로 삭제하면 다음 파일로 이어지며, 마지막 파일은 이전 파일로 이동합니다.

폴더 동기화와 비교

하위 폴더까지 비교하고 단방향·양방향으로 동기화합니다. 실행할 변경 목록을 먼저 확인하고 제외·삭제 규칙을 저장합니다. 이미지 비교와 외부 비교 앱 연결도 지원합니다.

서버와 전송 관리

S3·Backblaze B2·Rackspace 연결, Dropbox 공유 링크, 원격 편집 변경 감지·업로드와 충돌 확인을 추가했습니다. 전송 대기열 순서·속도 제한·활동 기록을 관리합니다.

내게 맞는 작업 환경

임시보관함을 설정에서 켜거나 끄고(기본값: 사용), 단축키를 바꿉니다. 빠른 실행, 사용자 명령, 즐겨찾기 iCloud 동기화와 macOS 기본 터미널 열기를 지원합니다.

기본 앱으로 열기와 정보

더블클릭으로 기본 앱에서 엽니다. 연결된 앱이 없으면 macOS의 앱 선택 절차를 사용합니다. Finder 정보 가져오기에서 파일 정보와 연결 앱을 확인·변경합니다.

파일 정리와 기본 압축

순서 있는 이름 변경 규칙과 날짜·위치 삽입, 앱 잔여 파일 검토, 압축 내부 탐색·미리보기·선택 해제를 제공합니다. 기본 ZIP·TAR.GZ 압축은 일반판 기능입니다.

필요한 파일만 빠르게 찾기

파일 내용·크기·날짜 등 조건으로 검색하고 원격 폴더도 재귀 탐색합니다. 빠른 선택에서 이름·확장자 등 조건에 맞는 파일을 선택하거나 제외합니다.

파일 창에서 Git 작업까지

변경 상태를 확인하고 파일 추가·커밋·푸시·풀을 실행합니다. 저장소 작업을 파일 탐색 흐름 안에서 이어갑니다.

FileDesk Pro

파일 관리에서 편집·변환·공유까지. 아래 기능은 Pro 전용으로 준비하고 있습니다. 출시일과 가격은 추후 안내하며, 현재 공개 일반판 다운로드에는 포함되지 않습니다.

이미지 편집·변환

미리보기를 보며 자르기·회전·크기 조절. 흑백·반전·배경 제거·메타데이터 제거를 켜고 끕니다. JPG·PNG·HEIC·WebP·AVIF 등 형식 선택, 용량 줄이기, 이미지 합치기, PDF 묶기와 QR 읽기를 제공합니다. 콜라주는 최대 20장, 2~20장 각각 36개 템플릿과 사진 이동·확대·축소·테두리·배경 조절을 지원합니다. 사진 모양 12종(원형·하트·별·꽃·다각형 등)과 별도 모양 배치 12종을 선택할 수 있습니다. 사진과 콜라주에 글꼴을 정해 글자를 넣고 이동·회전·크기를 조절합니다. 기존 사각형 격자 36종에 혼합 모양 템플릿 12종을 추가했습니다. 격자 배치와 믹스 템플릿을 모두 선택할 수 있습니다. 칸 크기는 모서리 드래그·숫자로 조절하고 Shift 드래그로 비율을 유지하며, 왼쪽 목록의 다중 선택도 지원합니다.

PDF 페이지·주석 편집

페이지 순서 변경·회전·삭제, 합치기·분할·추출·압축. 글·이미지·도형·강조·메모·서명을 추가하고 이동·크기 변경·삭제합니다. 영역 가리기, 워터마크·쪽 번호, 암호와 문서 정보를 관리합니다.

PDF 변환·인식·추가 도구

편집창에서 문서·이미지 변환, OCR, PDF/A, 웹 최적화, 메타데이터 제거, 비교·겹치기·복구를 바로 선택합니다. 스캔·카메라·화면 가져오기, 문서 묶기와 송장 자료 도구도 제공합니다.

오디오·스테레오·벨소리

파형에서 구간을 남기거나 삭제하고 속도·음량·음소거를 조절합니다. 스테레오 L/R 파형을 따로 편집하고 미리듣습니다. MP3·M4A·WAV·FLAC·Opus·AIFF 또는 30초 이내 M4R 벨소리로 저장합니다.

영상 편집·변환

미리보기에서 구간 편집, 속도·음량 조절. MP4·MOV·MKV·WebM 등 변환, 오디오 추출, 용량 줄이기, HEVC 변환, 장면 캡처와 GIF 만들기를 제공합니다.

문서·자막·일괄 작업

지원 문서의 PDF·Word·HWPX·TXT·RTF·HTML·ODT 변환과 PDF의 XLSX·PPTX 내보내기. SRT·VTT·SMI 자막 변환, 이미지·PDF OCR, 여러 파일 일괄 실행과 저장 폴더 선택을 지원합니다.

고급 압축 만들기·해제

7Z·ZIP·TAR 계열, DMG·ISO·Zstandard 등 만들기와 RAR·분할 파일·WPRESS 등의 해제. 형식별 암호·파일명 암호화·분할·압축 수준·개별 압축·검증·프리셋을 지원하며 Keka 설치가 필요 없습니다.

시간 제한 인터넷 공유

파일·폴더를 1분~7일 동안 인터넷 링크로 공유하고 즉시 중지할 수 있습니다. 공유 목록, 접속 시각·IP·브라우저·전송 상태와 CSV 기록을 제공합니다. 받는 사람은 앱 설치 없이 브라우저로 받습니다.

원하는 터미널 앱 선택

설치된 iTerm2·Ghostty·Warp 등이나 직접 지정한 터미널 앱으로 폴더와 SSH 작업을 엽니다. 일반판은 macOS 기본 Terminal만 사용하며, 다른 앱 선택은 Pro 활성화 후 제공됩니다.

지원 범위와 이용 조건

PDF/A와 영역 가리기는 페이지를 이미지로 고정합니다. EPUB은 텍스트 기반, SVG는 이미지 기반이며 변환 시 원본 서식 보존에는 한계가 있습니다. 암호 해제에는 필요한 암호가 있어야 합니다. 송장 XML은 XRechnung 형식이며 한국 전자세금계산서 발행 기능은 아닙니다.

압축 옵션은 형식에 따라 다릅니다. RAR·WPRESS는 해제만 지원합니다. 독립적으로 사용 가능한 외부 엔진을 각 라이선스에 따라 포함합니다. 오디오 한 채널의 구간 삭제는 싱크 유지를 위해 무음으로 남습니다.

공유하는 Mac에 Tailscale 설치·로그인과 최초 Funnel 승인이 필요합니다. Mac을 켜고 FileDesk·Tailscale과 인터넷 연결을 유지해야 합니다. 접속 기록은 실명 확인이 아니며, 만료되거나 중지되어도 이미 받은 사본은 회수되지 않습니다.

  • 폴더 동기화와 비교 — 하위 폴더까지 비교하고 단방향·양방향으로 동기화합니다. 실행할 변경 목록을 먼저 확인하고 제외·삭제 규칙을 저장합니다. 이미지 비교와 외부 비교 앱 연결도 지원합니다.

  • 파일 창에서 Git 작업까지 — 변경 상태를 확인하고 파일 추가·커밋·푸시·풀을 실행합니다. 저장소 작업을 파일 탐색 흐름 안에서 이어갑니다.
