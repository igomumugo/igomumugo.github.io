01 / 탐색

여러 폴더를 함께

03 / 정리

파일 작업을 한곳에

복사·이동·이름 변경과 임시보관함으로 파일을 정리합니다.

04 / 임시보관함

파일을 잠시 모아 두세요

05 / 테마

내 색으로 만드는 화면

색상표에서 원하는 테마 색상을 고르고 라이트·다크 모드를 선택하세요.

06 / 폴더 꾸미기

한눈에 알아보는 폴더

07 / 연결

클라우드도 같은 창에서

Google Drive·OneDrive·pCloud·Dropbox와 서버의 파일을 선택한 창에서 탐색합니다.

08 / TAILDROP

내 기기로 바로 전송

Tailscale로 연결된 기기를 선택해 파일을 보냅니다. Mac과 Windows 사이에서도 사용할 수 있습니다.

09 / 정리 도구

반복 작업을 가볍게

일반판 1.24의 새로운 편의기능과 주요 도구

탐색부터 동기화·검색·정리까지, 아래 기능은 지금 내려받는 일반판 1.24에 포함됩니다.

일반판 기능 둘러보기

다운로드와 임시보관함

다운로드 폴더를 ‘추가된 날짜’로 정렬하세요. 임시보관함에서 항목을 선택한 뒤 스페이스 바로 훑어보거나 ‘창에서 보기’로 원본 위치를 열 수 있습니다. 파일 이름은 색상이나 단색으로 표시할 수 있습니다.

색상 태그와 목록 정리

체크된 색상을 다시 누르면 이름을 바꾼 태그도 해당 색상으로 해제할 수 있습니다. 다운로드 목록을 열 때 첫 줄이 열 제목 아래에 가려지던 문제와 일괄 이름 변경에서 큰 시작 번호를 처리하던 문제를 고쳤습니다. iCloud의 색상 판별을 고려해 직접 이름을 붙인 회색 태그는 보존합니다.

건너뛴 동기화 충돌 다시 확인하기

이번 동기화에서 건너뛴 충돌은 앱을 다시 열어도 다음 비교에 표시됩니다. 수정 시각은 양쪽 저장소가 공통으로 기록하는 정밀도에 맞춰 비교합니다.

실행 취소와 원격 파일 편집

실행 취소 전에는 해당 경로에 있는 항목이 원래 작업의 대상과 같은지 확인합니다. 원격 파일의 편집 세션은 각각 따로 추적합니다.

Pro 기능 둘러보기

사진을 잇거나 앨범 페이지로 꾸미기

여러 사진을 한 화면에 이어 붙이거나 테이프와 핀으로 꾸민 앨범형 사진 템플릿을 선택하세요. 사진마다 액자 50종과 마스크 50종을 조합할 수 있습니다.

이미지에서 작업 창의 색 고르기

이미지에서 팔레트를 만들고 라이트 모드와 다크 모드에서 각 파일 창에 쓸 색을 지정하세요. 완성한 팔레트는 저장해 다시 적용할 수 있습니다.

파일 편집과 분할 압축 해제

이미지 크기를 바꾸고 PDF에 주석을 달거나 오디오와 영상의 필요한 구간을 잘라낼 수 있습니다. 번호가 매겨진 분할 압축 파일은 중간 조각이 빠지면 압축 해제를 중단합니다.

지원 범위와 이용 조건

PDF/A와 영역 가리기는 페이지를 이미지로 고정합니다. EPUB은 텍스트 기반, SVG는 이미지 기반이며 변환 시 원본 서식 보존에는 한계가 있습니다. 암호 해제에는 필요한 암호가 있어야 합니다. 송장 XML은 XRechnung 형식이며 한국 전자세금계산서 발행 기능은 아닙니다.

압축 옵션은 형식에 따라 다릅니다. RAR·WPRESS는 해제만 지원합니다. 독립적으로 사용 가능한 외부 엔진을 각 라이선스에 따라 포함합니다. 오디오 한 채널의 구간 삭제는 싱크 유지를 위해 무음으로 남습니다.

공유하는 Mac에 Tailscale 설치·로그인과 최초 Funnel 승인이 필요합니다. Mac을 켜고 FileDesk·Tailscale과 인터넷 연결을 유지해야 합니다. 접속 기록은 실명 확인이 아니며, 만료되거나 중지되어도 이미 받은 사본은 회수되지 않습니다.

CLOUD CONNECTIONS

쓰던 클라우드를 그대로, FileDesk에서

Google Drive for desktop, OneDrive, pCloud, Dropbox의 공식 동기화 앱에 로그인해 두면 FileDesk가 동기화 폴더를 찾아 바로 엽니다. 별도 인증이나 사용자 수 제한이 없어 대부분의 사용자에게 권장하는 방법입니다.

고급: 공식 앱 없이 FileDesk에서 브라우저로 직접 로그인해 폴더를 탐색하고 파일을 업로드하거나 내려받을 수도 있습니다. 직접 연결은 공식 동기화 앱과 별도로 관리됩니다.

로그인 정보는 사용자의 컴퓨터에 암호화해 저장합니다. 클라우드 파일은 사용자의 기기와 선택한 서비스 사이에서 전송되며, FileDesk 운영자의 서버를 거치지 않습니다. 자세한 내용은 개인정보처리방침을 확인하세요.

Google Drive 직접 로그인(고급)은 공개 검증이 진행 중입니다.

Google 인증 앱은 프로덕션으로 전환했습니다. 공개 검증이 완료되기 전에는 미확인 앱 안내와 사용자 수 제한이 남습니다. 최신 Mac 설치 파일은 브라우저 Google 로그인 설정을 포함하며, 이전에 배포된 파일은 새로 내려받아야 합니다. 서비스가 권한을 철회하거나 재인증을 요구하면 다시 로그인해야 합니다.
