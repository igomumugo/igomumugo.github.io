개인정보처리방침

최종 작성일: 2026년 10월 18일 · 문의: ifreemumu@gmail.com

이 방침은 FileDesk 데스크톱 앱의 클라우드 직접 연결 기능과 이 소개 웹사이트에 적용됩니다. FileDesk는 사용자가 자신의 파일을 탐색하고 전송할 수 있도록 제공하는 파일 매니저입니다.

1. 접근하는 정보와 목적

클라우드 연결을 선택하고 서비스의 동의 화면을 승인하면 FileDesk는 해당 계정의 파일·폴더 이름, 식별자, 경로, 파일 유형, 크기, 수정일 등 파일 목록 정보를 읽습니다. 사용자가 다운로드·업로드를 실행하면 선택한 파일의 내용을 읽거나 전송하며, 새 폴더 만들기를 실행하면 해당 서비스에 폴더를 생성합니다. 공유 드라이브 등 저장소를 선택하는 데 필요한 계정·드라이브 정보도 처리할 수 있습니다.

Google Drive에서는 https://www.googleapis.com/auth/drive 범위를 요청합니다. 이 범위는 Google Drive 파일 보기·수정·생성·삭제를 허용합니다. 현재 FileDesk 클라우드 화면의 기능은 폴더 탐색, 다운로드, 업로드, 새 폴더 만들기, 그리고 사용자가 선택한 항목의 이름 변경과 삭제입니다. 삭제한 항목의 복원 여부는 해당 서비스의 휴지통 정책을 따릅니다. 권한을 허용하지 않으면 Google Drive 직접 연결은 사용할 수 없으며, 로컬 파일 기능은 계속 사용할 수 있습니다.

2. 로그인 정보와 저장 위치

계정 비밀번호는 해당 서비스의 브라우저 로그인 화면에 입력합니다. FileDesk는 계정 비밀번호를 직접 받지 않습니다. 연결을 유지하기 위한 OAuth 액세스 토큰과 갱신 토큰은 컴퓨터의 앱 데이터 영역에 암호화하여 저장합니다. macOS에서는 암호화 키를 키체인에 보관합니다. 계정 표시 이름과 연결 대상 같은 설정은 로컬 앱 설정에 저장합니다. 사용자가 내려받은 파일은 사용자가 선택한 폴더에 남습니다.

FileDesk 운영자는 별도의 서버로 클라우드 계정의 파일이나 로그인 토큰을 수집하지 않습니다. 업로드와 다운로드는 앱에 포함된 rclone 연결 엔진을 통해 사용자의 기기와 클라우드 서비스 사이에서 이루어집니다.

3. 정보 이용과 공유

Google API에서 받은 정보는 사용자에게 보이는 파일 탐색·전송 기능 제공에만 사용합니다. 광고 타기팅, 데이터 판매, 대출·신용 평가, 일반 목적의 AI 모델 학습에 사용하지 않습니다. 클라우드 파일을 광고업체·데이터 중개업체·분석업체에 제공하지 않습니다. FileDesk 운영자는 사용자의 클라우드 파일을 열람하지 않습니다.

사용자가 파일을 내려받은 뒤 다른 서버·클라우드·장치로 보내는 명령을 직접 실행하면 해당 수신처로 파일이 전송됩니다. FileDesk는 그 동작에 필요한 파일만 사용자가 지정한 수신처에 전송합니다. Google, Microsoft, pCloud 및 사용자가 선택한 다른 서비스의 로그인·저장·처리에는 각 서비스의 정책이 적용됩니다.

FileDesk의 Google API 정보 이용 및 다른 앱으로의 이전은 Limited Use 요구사항을 포함한 Google API Services User Data Policy를 따릅니다.

4. 보관 기간과 연결 해제

연결 정보는 사용자가 연결을 해제할 때까지 로컬에 보관합니다. 일시적인 네트워크 오류로 계정을 삭제하지 않습니다. FileDesk에서 해당 계정의 연결 해제를 선택하면 해당 계정의 로컬 로그인 정보가 제거됩니다. 이미 내려받은 파일과 클라우드 원본 파일은 삭제되지 않으며, 사용자가 파일 위치에서 별도로 관리할 수 있습니다.

Google 계정의 서드 파티 연결 관리에서도 FileDesk의 접근 권한을 철회할 수 있습니다. 서비스 정책·보안 조치·권한 철회 등으로 다시 로그인이 필요할 수 있습니다. 운영자는 클라우드 파일을 서버에 보관하지 않으므로 해당 파일의 삭제는 사용자의 기기 또는 클라우드 서비스에서 수행해야 합니다.

5. 지원 문의와 웹사이트

지원 이메일로 문의하면 사용자가 직접 보낸 이메일 주소와 문의 내용을 문의 응대에 사용합니다. 비밀번호, 인증 토큰, 민감한 파일 내용은 보내지 마세요. 문의 기록 삭제를 원하면 같은 지원 주소로 요청할 수 있습니다. 이 사이트는 자체 광고·행동 분석 스크립트나 추적 쿠키를 사용하지 않습니다. 사이트 호스팅 제공자는 페이지 제공과 보안을 위해 IP 주소 등 접속 기록을 처리할 수 있습니다.

업데이트 확인. FileDesk는 하루 한 번(또는 사용자가 ‘업데이트 확인…’을 누를 때) GitHub API에 최신 공개 버전을 묻는 익명 요청을 한 번 보냅니다. 요청에는 계정 정보·쿠키·파일 정보가 포함되지 않으며, 앱 버전이 담긴 User-Agent만 전송됩니다. GitHub은 서비스 제공을 위해 IP 주소 등 접속 기록을 처리할 수 있습니다. FileDesk 메뉴의 ‘자동으로 업데이트 확인’을 끄면 자동 요청을 보내지 않습니다.

6. 변경과 연락처

데이터 처리 방식이 변경되면 이 페이지의 내용과 최종 작성일을 갱신합니다. 권한 범위를 변경해야 하는 경우 서비스에서 추가 동의를 요구할 수 있습니다. 개인정보 관련 문의: FileDesk, ifreemumu@gmail.com.

English summary for users and reviewers

FileDesk is a desktop file manager. Its direct cloud connection reads file and folder metadata to display your storage and transfers file content only for operations you initiate. The Google Drive integration requests the full drive scope, which permits viewing, editing, creating and deleting Drive files. The current cloud interface provides browsing, downloading, uploading, creating folders, and renaming or deleting items the user selects. Whether deleted items can be restored depends on the service's trash policy. Once a day, or when the user chooses Check for Updates, FileDesk sends one anonymous request to the GitHub API for the latest public version; it carries no account, cookie or file data and can be turned off in the FileDesk menu.

OAuth tokens are encrypted on the user's computer; on macOS, the encryption key is stored in Keychain. Account labels and connection preferences are stored locally. FileDesk's operator does not receive or store cloud files or OAuth tokens on an operator-controlled server. The bundled rclone engine communicates directly with the selected provider. Cloud passwords are entered on the provider's login page.

Google data is used only for user-facing file management. It is not sold, used for targeted advertising, credit assessments or training general-purpose AI models. FileDesk's operator does not read users' cloud files. Transfers to another service occur only when the user explicitly chooses a destination and starts that operation. FileDesk's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Disconnecting removes the account's local credentials; downloaded files and cloud originals remain under the user's control. Access may also be revoked through Google Account connections. Temporary network failures do not delete saved accounts, but provider policies may require reauthentication. Support messages are used to answer the user's inquiry; contact ifreemumu@gmail.com for privacy questions or deletion of support correspondence.
