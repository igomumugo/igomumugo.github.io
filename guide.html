일반판 1.25 사용 설명서

공개 일반판 1.25(빌드 46)에서 도구 막대 배치, 임시 보관함과 이름 변경을 따라 해 보세요. 언어를 바꾸면 같은 장면을 해당 앱 언어로 볼 수 있습니다.

도구 막대 왼쪽 위의 ⠿ 손잡이를 끌면 놓을 수 있는 위치가 표시됩니다. 원하는 가장자리에서 놓으세요. 설정 → 도구 막대에서도 두 도구 막대의 위치를 고를 수 있습니다.

왼쪽 메뉴 맨 아래의 설정을 누르거나 ⌘,를 누르세요. 왼쪽 목록에서 범주를 고릅니다. 모두 기본값으로…를 누르면 도구 막대·왼쪽 메뉴·보관함·터미널 설정이 기본값으로 돌아가며, 테마와 등록한 런처는 유지됩니다.

파일을 임시 보관함에 끌어 놓으세요. 보관 항목을 선택한 뒤 스페이스 바를 누르면 훑어볼 수 있습니다. 다른 창에서 정리할 때도 같은 보관함을 사용합니다.

여러 파일을 선택하고 파일 메뉴에서 ‘고급 일괄 이름 변경…’을 여세요. ‘앞에 추가’에 2026-를 입력하고 표에서 변경 전후 이름을 확인한 뒤 ‘이름 변경’을 누르세요.

사용자 도구 모음

  1. 자주 쓰는 앱·폴더·파일을 런처로 끌어오세요. ＋ 버튼의 ‘파일·폴더·앱 추가’로 선택해도 됩니다. 버튼을 클릭하면 등록한 항목을 엽니다. 웹 주소도 바로가기로 추가할 수 있습니다.

  2. 브라우저에서 원하는 아이콘 이미지를 우클릭해 ‘이미지 복사’를 선택하거나, 이미지 앱에서 그림을 복사하세요. FileDesk의 사용자 도구 모음 버튼을 우클릭해 ‘아이콘 변경…’을 열고 ‘붙여넣기’ 또는 ⌘V를 누릅니다.

  3. 미리보기에서 그림을 확인하고 ‘적용’을 누르세요. 이미지 비율을 유지해 버튼에 맞춰지며 다음부터 그 그림으로 항목을 열 수 있습니다. 같은 창에서 이모지나 이미지 파일을 선택하거나 ‘기본 아이콘’으로 되돌릴 수 있습니다.

화면 캡처와 문자 인식

도구 막대의 화면 캡처에서 전체 화면, 창 또는 영역을 선택하세요. ‘더 보기’에서 같은 영역을 다시 찍거나 3초 뒤에 찍을 수 있습니다. 긴 페이지는 스크롤 캡처 영역 안에서 위나 아래로 천천히 스크롤한 뒤 완료하세요. 미리보기에서 PNG 저장, 복사, 텍스트 추출을 선택할 수 있습니다. 이미지 파일이나 클립보드 이미지도 열 수 있습니다. 자동 스크롤에는 macOS 손쉬운 사용 권한이 필요합니다. 직접 스크롤할 수도 있습니다.

텍스트 추출로 읽을 부분을 드래그하고 결과 창에서 원문을 확인하거나 수정하세요. macOS 14.4 이상에서는 번역을 열 수 있습니다. 원문이나 번역문을 복사하거나, 임시 보관함에 자동 이름 또는 직접 정한 이름으로 저장하세요. 창 캡처에서는 직전에 사용한 앱과 현재 FileDesk 창을 따로 선택할 수 있습니다.

여러 언어가 섞인 문서에서는 결과 창에 표시되는 감지 언어를 확인한 뒤 인식된 글자를 수정할 수 있습니다.

화면 녹화

도구 막대에서 녹화를 열고 전체 화면·창·영역 중 하나를 고르세요. 시스템 소리와 마이크를 선택하고 시작 지연을 0~300초로 정할 수 있습니다. MP4 저장 위치를 지정하고 카운트다운이 끝나면 녹화가 시작됩니다. 녹화를 마치려면 중지를 누르세요. 단축키 설정에서 다른 앱을 사용하는 동안 실행할 캡처·녹화 명령도 지정할 수 있습니다.

macOS가 공유할 항목을 물으면 캡처하거나 녹화할 화면 또는 창을 선택하세요. 내 목소리도 담으려면 녹화 옵션에서 마이크를 켜고 macOS의 마이크 접근을 허용하세요.

주석·스탬프·모자이크

캡처 미리보기에서 편집을 열고 펜·화살표·도형·텍스트를 추가하거나 이미지를 자르세요. 왼쪽에서 평면·입체 스탬프와 글자 스타일을 고르고, 오른쪽 레이어 목록에서 주석의 위치·크기·순서를 조절하세요. 워터마크, 흑백·단색 톤, 테두리와 그림자 효과도 적용할 수 있습니다.

평면 또는 입체 스탬프를 고르세요. 클릭하면 지정한 크기로 놓이고, 드래그하면 원하는 크기로 배치됩니다.

선택 도구로 여러 개체를 둘러싼 뒤 함께 옮기거나 모서리로 크기를 바꾸세요. 레이어 순서를 앞뒤로 바꿀 수 있습니다. 말풍선은 모양·꼬리·배경을, 글자는 글꼴·크기·굵기·기울임을 정합니다. 효과 탭에서는 흐림 반경과 모자이크 크기, 단색 톤을 조절하세요.

화살표나 포인터 같은 방향 스탬프를 선택하고 회전 손잡이를 끌거나 각도를 입력하세요. 말풍선 윤곽은 꼬리까지 이어집니다. 필요 없는 주석은 우클릭해 개체 삭제를 선택하세요.

말풍선의 채우기·테두리·글자 색과 테두리 두께를 따로 정하세요. 투명 배경을 고르면 뒤의 이미지가 보입니다. 효과에서 흐림 반경이나 모자이크 블록 크기를 맞춘 다음 적용하세요. 편집 창의 ‘파일로 저장’으로 PNG를 바로 내보낼 수 있습니다.

도형이나 선을 그리기 전에 두께를 정하세요. 다각형은 각의 수를 고르고, 순서 스탬프는 다음 표시를 확인하거나 순서를 처음부터 시작할 수 있습니다. 영역 모자이크를 드래그한 뒤 같은 영역을 다시 클릭하면 블록 크기를 조절할 수 있습니다.

픽셀 측정과 QR 코드

디자인 도구에서 눈금자를 드래그해 픽셀 거리를 재거나 각도기로 세 점을 찍으세요. Shift는 각도기를 15°씩, 선을 45°씩 맞춥니다. 십자선은 클릭해 기준점을 고정하고 돋보기·십자선은 화살표 키로 1픽셀씩 이동합니다. QR 버튼으로 화면의 코드를 클릭하거나 영역·파일·클립보드·선택 이미지를 읽고 결과를 복사하거나 링크를 여세요. Shift를 누르고 도형을 그리면 정사각형·원·정다각형이 됩니다. 스탬프는 찍기 전에 반투명 미리보기로 위치를 맞출 수 있습니다.

클립보드와 임시 보관함

도구 막대에서 클립보드를 열고 파일·이미지·텍스트 항목을 고르세요. 스페이스바로 미리보고 위아래 화살표로 다른 항목을 확인할 수 있습니다. 다시 복사하거나 보관함에 저장하세요. 보관함에서도 선택 항목을 미리보거나 위쪽 파일 창에서 열 수 있습니다.

Pro를 실행한 상태에서 파일·이미지·텍스트를 복사하면 기록에 추가됩니다. 클립보드의 보관 설정에서 최대 항목 수(1~10,000개)와 자동 삭제 기간(1~3,650일)을 정하세요. 한도에 도달하면 오래된 항목부터 삭제됩니다.

기록을 한꺼번에 지우려면 ‘전체 비우기’를 선택하고 확인하세요.

영상 타임라인 편집

미디어 목록에서 영상·사진·음성을 타임라인으로 끌어오세요. 클립 양끝을 끌어 다듬거나 재생 위치에서 분할한 뒤, 선택 구간만 남기거나 삭제합니다. 클립은 0.1~5배속으로 재생할 수 있고, 레이어 이름을 두 번 클릭해 바꾸거나 위아래로 끌어 겹침 순서를 정할 수 있습니다. 전환 갤러리에서 효과와 길이를 고른 뒤 스페이스바로 결과를 확인하세요.

전환 갤러리에서 효과 33가지를 비교하거나 컷을 선택해 두 클립을 바로 이으세요. 화면 비율을 정한 뒤 전체 프레임을 맞추거나 화면을 채우도록 잘라낼 수 있습니다.

영상 아래의 파형 경계선을 끌어 음량을 바꾸고 클립 양끝을 끌어 길이를 조절하세요. 레이어 이름을 두 번 클릭해 바꾸고, 위아래로 끌어 겹침 순서를 정할 수 있습니다.

음성 탭에서 스피커 아이콘으로 음소거 상태를 확인하고 음량, 음높이, 페이드인·아웃을 조절하세요. 음성을 분리하면 시작 위치를 옮길 수 있습니다. 자막 탭에서는 표시 시간, 글꼴, 크기와 10가지 모양을 고릅니다. 편집 결과를 재생한 뒤 전체 타임라인 또는 선택 클립을 저장하세요.

자막 편집창에서 색상 견본을 누르거나 HEX 값을 입력해 글자색을 정하세요. 미리보기에서 색을 확인한 뒤 ‘적용’을 누르면 저장 영상에도 반영됩니다.

화면 비율과 ‘잘라서 채우기’를 선택한 뒤, 미리보기 영상을 끌어 프레임 안에 담을 장면을 정하세요. 타임라인에서는 영상과 아래쪽 파형이 함께 이동하고 잘립니다. ‘음성 트랙 분리’를 누르면 음성을 따로 편집할 수 있습니다.

클립에서 ‘모자이크 · 흐리기’를 열고 영상 위를 드래그하세요. 각 영역의 효과와 강도를 따로 지정하거나 Shift를 누른 채 여러 영역을 클릭해 한꺼번에 바꿀 수 있습니다. 영역 안을 끌면 이동하고, 한 영역의 모서리를 끌면 크기가 바뀝니다. ‘적용’을 누르면 클립 전체에 반영됩니다. 효과를 없애려면 해당 영역을 선택하고 ‘선택 영역 삭제’를 누른 뒤 적용하세요.

저장할 때 전체 타임라인, 선택한 클립 또는 영상·음성 파일 따로 저장을 고를 수 있습니다. 전환 효과는 길이도 조정할 수 있습니다.

타임라인 전체 또는 선택한 클립을 MP4, MOV, MKV, WebM으로 저장하세요. 소리만 저장할 때는 MP3, M4A, WAV를 선택할 수 있습니다. 소리가 있는 영상을 내보낼 때는 영상과 음성을 별도 파일로 저장할 수도 있습니다.

작업 공간과 설정

시스템 도구 막대와 런처를 각각 창의 네 가장자리 중 원하는 곳에 배치하세요. 사이드바 섹션은 접거나 끌어서 순서를 바꿀 수 있습니다. 사이드바 하단에서 설정을 열면 Pro에서는 일반, 화면 모양, 도구 막대, 왼쪽 메뉴, 임시보관함, 전송, 라이선스를 한 창에서 관리합니다.

시스템 도구 막대나 런처의 손잡이 또는 빈 곳을 잡고 원하는 창 가장자리 쪽으로 끕니다. 커서 옆에서 대상 위치를 확인한 뒤 놓으세요. 가운데 십자 근처에 놓으면 막대가 원래 자리에 남습니다.

일반 설정에서 앱 언어와 로그인 시 자동 시작을 선택하세요. 파일 이름을 컬러로 표시한 뒤 파일을 우클릭하면 같은 확장자의 파일 이름에 공통으로 적용할 색을 정할 수 있습니다.

Pro 전용 편집 도구와 사용자 아이콘은 라이선스를 활성화한 뒤 사용할 수 있습니다. 사이드바의 설정에서 라이선스 상태를 확인하세요. 같은 Mac에서 앱을 업데이트하면 기존 활성화 상태를 이어서 사용합니다.

이미지·PDF와 파일 도구

파일을 더블클릭하면 macOS 기본 앱으로 열립니다. 편집할 때는 파일이나 보관함에서 변환 도구를 여세요. 원본 옆이나 선택한 폴더에 새 파일을 저장하고 FileDesk 패널에서 확인할 수 있습니다. 변환 목록에서는 결과를 보관함에도 추가할 수 있습니다.

이미지 편집·변환

이미지·PDF 편집기는 밝은 모드와 어두운 모드를 지원합니다. 파일 목록에서 편집할 항목을 선택하고 가운데 미리보기를 보며 오른쪽에서 도구를 고르세요.

미리보기에서 사진을 자르거나 회전하고, 크기를 바꾸거나 좌우·상하로 뒤집으세요. 배경이나 메타데이터를 제거하고 JPG, PNG, HEIC, WebP, AVIF 등으로 저장할 수 있습니다. 여러 이미지를 한 PDF로 묶거나 이미지 속 QR 코드도 읽을 수 있습니다.

이미지를 선택해 이미지 편집·변환을 열고 자르기·회전·크기를 조절합니다. 형식 버튼을 누른 뒤 저장·변환을 실행하세요. 흑백·반전은 다시 누르면 해제됩니다. 배경 제거는 피사체가 뚜렷한 사진에 적합하며 투명 결과는 PNG로 저장합니다. 인식 실패 시 다른 편집과 원본 미리보기를 유지합니다.

PDF 페이지·주석 편집

PDF 페이지를 재정렬·회전·삭제하거나 여러 문서를 합치고 나눌 수 있습니다. 글자, 이미지, 도형, 메모, 서명을 주석으로 추가하고 추가한 항목을 이동하거나 크기를 바꾸세요. 영역 가리기, 워터마크, 쪽 번호와 암호 설정도 지원합니다.

PDF 편집창에서 페이지를 선택해 순서·회전·삭제를 조정하고 필요한 주석을 추가합니다. 글·이미지·서명 등을 선택해 이동·크기 변경·삭제한 뒤 새 파일로 저장합니다.

PDF 변환·인식·추가 도구

편집창에서 문서·이미지 변환, OCR, PDF/A, 웹 최적화, 메타데이터 제거, 비교·겹치기·복구를 바로 선택합니다. 스캔·카메라·화면 가져오기, 문서 묶기와 송장 자료 도구도 제공합니다.

PDF 편집창에 표시된 변환·추가 도구에서 원하는 출력 형식이나 OCR 등을 바로 고릅니다. 페이지 범위·언어·암호 등 해당 옵션을 확인하고 실행하세요. 지원 형식과 변환 한계는 아래 이용 조건을 확인하세요.

표지를 붙여 제출 서류를 묶고, 송장 PDF나 XRechnung XML을 만드세요. 스캔·카메라·화면 캡처에서 페이지를 가져오거나, 여러 쪽을 한 장에 배치하고 출력 설정을 프로필로 저장할 수 있습니다. 보관용 PDF/A-1b·2b·3b는 페이지를 이미지로 고정합니다.

PDF/A와 영역 가리기는 페이지를 이미지로 고정합니다. EPUB은 텍스트 기반, SVG는 이미지 기반이며 변환 시 원본 서식 보존에는 한계가 있습니다. 암호 해제에는 필요한 암호가 있어야 합니다. 송장 XML은 XRechnung 형식이며 한국 전자세금계산서 발행 기능은 아닙니다.

오디오·스테레오·벨소리

파형에서 구간을 남기거나 삭제하고 속도·음량·음소거를 조절합니다. 스테레오 L/R 파형을 따로 편집하고 미리듣습니다. MP3·M4A·WAV·FLAC·Opus·AIFF 또는 30초 이내 M4R 벨소리로 저장합니다. 오디오 한 채널의 구간 삭제는 싱크 유지를 위해 무음으로 남습니다.

오디오 편집창에서 파형 구간을 선택하고 전체·왼쪽·오른쪽 채널을 고릅니다. 스테레오 L/R 파형을 따로 확인하며 편집 후 미리듣고 저장합니다. 벨소리는 30초 이내 구간을 M4R로 내보내며 기기로 전송·등록하는 과정은 별도입니다.

문서·자막·일괄 작업

지원 문서의 PDF·Word·HWPX·TXT·RTF·HTML·ODT 변환과 PDF의 XLSX·PPTX 내보내기. SRT·VTT·SMI 자막 변환, 이미지·PDF OCR, 여러 파일 일괄 실행과 저장 폴더 선택을 지원합니다.

변환 도구에서 지원하는 문서·자막 형식과 대상 파일을 선택합니다. 여러 파일을 일괄 처리할 때는 출력 형식과 저장 폴더를 확인하고 진행 결과에서 생성 파일을 엽니다.

고급 압축 만들기·해제

7Z·ZIP·TAR 계열, DMG·ISO·Zstandard 등 만들기와 RAR·분할 파일·WPRESS 등의 해제. 형식별 암호·파일명 암호화·분할·압축 수준·개별 압축·검증·프리셋을 지원하며 별도 앱 설치가 필요 없습니다.

압축 만들기에서 출력 확장자를 먼저 고르면 그 형식에 맞는 암호·분할·압축 수준 등이 표시됩니다. 고급 압축 엔진이 포함되어 별도 앱 설치는 필요 없으며, 해제할 때 암호·분할 파일과 저장 위치를 확인합니다.

지원 형식에 따라 압축 수준, 스레드 수, 분할 크기, 암호, 파일 이름 암호화를 고르세요. 항목별 압축, 폴더 내용만 묶기, Mac 메타데이터 처리, 결과 검증을 설정할 수 있습니다. 암호를 제외한 설정은 프리셋으로 저장됩니다.

압축 옵션은 형식에 따라 다릅니다. RAR·WPRESS는 해제만 지원합니다. 독립적으로 사용 가능한 외부 엔진을 각 라이선스에 따라 포함합니다.

시간 제한 인터넷 공유

파일·폴더를 1분~7일 동안 인터넷 링크로 공유하고 즉시 중지할 수 있습니다. 공유 목록, 접속 시각·IP·브라우저·전송 상태와 CSV 기록을 제공합니다. 받는 사람은 앱 설치 없이 브라우저로 받습니다. 보내는 Mac에는 Tailscale 로그인과 최초 Funnel 승인이 필요합니다.

파일·폴더를 여러 개 선택해 시간 제한 인터넷 공유를 엽니다. 파일·폴더 추가 또는 드래그로 목록을 늘리고 필요 없는 항목은 목록에서 제거합니다. 공유 시간을 정해 시작한 후 외부 확인이 끝난 링크를 전달하세요. 여러 파일·폴더는 ZIP 사본으로 공유하고 접속·다운로드 기록 탭에서 기록을 확인합니다.

공유하는 Mac에 Tailscale 설치·로그인과 최초 Funnel 승인이 필요합니다. Mac을 켜고 FileDesk·Tailscale과 인터넷 연결을 유지해야 합니다. 접속 기록은 실명 확인이 아니며, 만료되거나 중지되어도 이미 받은 사본은 회수되지 않습니다.

원하는 터미널 앱 선택

설치된 iTerm2·Ghostty·Warp 등이나 직접 지정한 터미널 앱으로 폴더와 SSH 작업을 엽니다. 일반판은 macOS 기본 Terminal만 사용하며, 다른 앱 선택은 Pro 활성화 후 제공됩니다.

Pro 활성화 후 설정의 터미널 항목에서 설치된 앱을 고르거나 앱을 직접 지정합니다. 현재 폴더에서 터미널 열기나 SSH 작업을 실행해 선택한 앱으로 연결합니다.

사진 콜라주

사진을 최대 20장까지 넣으세요. 2장 이상이면 격자 36종을 고를 수 있고, 모자이크 24종과 앨범 24종도 제공합니다. 사진마다 액자 50종과 마스크 50종을 조합하고 글자를 더할 수 있습니다.

선택 영역 위의 둥근 조절점을 끌어 사진 칸, 액자, 마스크 또는 텍스트를 돌립니다. Shift를 누른 채 끌면 15° 단위로 회전합니다.

사진 칸은 사각형·원형·하트·별 등 12가지 모양 중에서 고르세요. 사진 칸을 클릭하고 네 모서리 손잡이를 드래그해 크기를 바꿉니다. Shift 드래그는 현재 비율을 유지합니다. 모양 탭에서 가로·세로 픽셀을 입력하고 비율 유지 또는 크기 초기화를 선택할 수도 있습니다. 칸 이동은 프레임 자체를, 구도 이동은 칸 안의 사진을 옮깁니다. 왼쪽 목록은 ⌘ 클릭으로 다중 선택, ⇧ 클릭으로 범위 선택, ⌘A로 전체 선택합니다. 선택한 사진을 함께 제거·순서 변경·모양 변경·자동 맞춤·크기 조절하며 실행 취소로 복원합니다. 사진을 교환해도 칸 모양과 크기는 유지됩니다. 글자 탭에서는 Mac 설치 글꼴·크기·색·정렬·회전·테두리·그림자를 조절하고 최대 20개 글상자(각 2,000자)를 넣습니다. 간격·여백·배경을 조절해 PNG/JPG로 저장하며 투명 영역은 PNG를 사용합니다. 원본은 변경하지 않습니다.

영역별 테마와 나만의 팔레트

추천 테마 8개에서 시작하거나 이미지에서 색을 추출하세요. 라이트·다크 모드별로 창, 사이드바, 도구 막대 두 개, 파일 창 여섯 개, 보관함, 선택 영역의 색과 투명도를 정할 수 있습니다. 자주 쓰는 색과 팔레트의 이름을 바꾸고, .fdtheme 파일로 저장하거나 다시 불러오세요.

설정의 화면 모양에서 이미지 팔레트를 열고 이미지를 고릅니다. 어울리는 색 추출을 누르면 라이트·다크 배색을 비교할 수 있습니다. 원하는 결과를 적용하거나 테마 파일로 저장하세요.

폴더 하나로 시작하는 일괄 이름 변경

폴더를 고르면 바로 아래의 파일만 목록에 담깁니다. 접두어·접미어, 찾기와 바꾸기, 일련번호, 날짜, 대소문자 규칙을 조합하고 적용 전에 새 이름을 확인하세요. 확장자는 유지되며 규칙을 저장해 다시 쓸 수 있습니다.

파일 메뉴에서 ‘이름 변경’을 선택하세요. 파일 하나를 선택하면 그 자리에서 이름을 입력할 수 있습니다. 두 개 이상이면 일괄 이름 변경 창이 열립니다. Pro 라이선스를 활성화하면 ‘폴더 선택…’으로 폴더 바로 안의 파일을 불러와 같은 규칙을 적용할 수 있습니다.

음성, 받아쓰기와 번역

문서·PDF·자막을 선택한 음성과 속도로 읽어 M4A로 저장하세요. macOS 26 이상에서는 오디오·영상의 말을 SRT·VTT·TXT로 받아쓰고, 설치된 언어 모델로 문서와 자막을 번역할 수 있습니다.

Pro에서 함께 쓰는 일반 기능

디스크 사용량, 스마트 폴더, Spotlight 본문 검색, 스프링 로딩 폴더, Finder 서비스·URL 자동화, 사진 메타데이터, 사용자 단축키와 도구막대 웹 바로가기도 사용할 수 있습니다.

런처의 추가 버튼과 폴더 기호에는 현재 테마 색이 적용됩니다. 앱과 문서는 원래 아이콘으로 구분할 수 있습니다.

다운로드 폴더 정리

도구 메뉴에서 다운로드 정리를 열면 파일마다 이동할 폴더가 표시됩니다. ⌘를 누른 채 클릭해 선택을 조정한 뒤 ‘선택한 파일 정리’를 누르세요. 목적지에 같은 이름이 있는 파일은 제외됩니다.

다운로드 중인 파일과 숨김 파일, 기존 폴더는 건너뜁니다. 정리 후 ⌘Z를 누르면 이번에 옮긴 파일을 한꺼번에 원래 위치로 돌려놓습니다.

캡처에 확대 렌즈와 라벨 넣기

디자인 도구에서 원형 또는 사각 확대를 고르고 캡처의 일부를 드래그하세요. 확대된 부분은 별도 레이어라 옮길 수 있습니다. 배율은 1.5배부터 4배까지, 렌즈 모양은 평면·볼록·오목 중에서 고르세요.

강조 도형은 테두리와 채우기 색을 따로 정할 수 있습니다. 테이프는 색과 무늬, 불투명도를 조절하세요. 도형이나 테이프를 더블클릭해 글을 쓰고 Return으로 확정하세요. Option-Return은 줄바꿈, Esc는 입력 취소입니다.

파일 비교와 폴더 병합

복사·이동 중 이름이 겹치면 양쪽 수정 시각을 확인하세요. 더 최신인 원본만 대치하거나, 같은 이름의 로컬 폴더 두 개를 병합할 수 있습니다. 남은 파일 충돌과 폴더 충돌에는 각각 같은 선택을 적용할 수 있습니다.

파일을 선택하고 해시 계산·비교를 여세요. SHA-256 등 일곱 가지 방식으로 여러 파일을 비교하거나, 전달받은 체크섬을 붙여 넣어 일치하는 파일을 확인할 수 있습니다.

폴더 동기화에서는 빈 폴더를 건너뛰고, 체크섬 없이 비교할 때 서버와의 시차나 몇 초의 수정 시각 차이를 허용할 수 있습니다. 저장한 동기화 규칙은 명령 팔레트에서 이름으로 찾아 여세요.

사진·음악 정보로 이름 바꾸기

일괄 이름 변경에서 메타데이터 삽입을 선택하세요. 예를 들어 {track}과 {title}을 조합하고, 태그가 비어 있을 때 쓸 문구를 정할 수 있습니다. 미리보기에서 이름을 확인한 뒤 적용하세요.

확장자를 바꾸거나 지우고, 각 단어의 첫 글자를 대문자로 바꿀 수 있습니다. 중복 이름에 번호를 붙이는 옵션도 규칙과 함께 저장됩니다. 다음에는 선택한 파일을 우클릭해 저장한 규칙을 적용하세요.

폴더 권한과 서버 연결

권한 편집에서 소유자·그룹·기타 사용자의 읽기·쓰기·실행 권한을 체크하거나 755 같은 8진수 값을 입력하세요. 하위 항목에 함께 적용할 때 기존에 실행 권한이 없던 일반 문서는 실행 파일이 되지 않습니다.

기본 폴더 뷰어를 켜면 다른 앱의 ‘Finder에서 보기’ 요청을 FileDesk Pro에서 열 수 있습니다. 서버 연결 창에서는 SMB 같은 공유 폴더의 시작 시 재연결을 설정하거나 macOS 화면 공유(VNC)를 열 수 있습니다.

암호가 걸린 압축 파일을 자주 연다면 암호를 이 Mac의 키체인에 저장하세요. 압축을 풀 때 저장한 암호를 차례로 시도하도록 선택할 수 있습니다.

파일 창 안에서 터미널 열기

설정의 일반 탭에서 터미널 앱을 ‘FileDesk 창 안에서 열기’로 지정하세요. 폴더에서 터미널을 열면 그 위치에서 셸이 시작됩니다. SSH 연결 창에서 터미널을 열면 같은 패널에 원격 세션이 열립니다.

필요한 폴더를 나란히 여세요.

  3. 창 사이 구분선을 드래그해 크기를 조절합니다. 구분선을 두 번 클릭하면 기본 비율로 돌아옵니다.

탭과 경로 이동

각 창 상단의 ＋ 또는 ⌘T로 탭을 추가합니다. 탭마다 다른 폴더를 열 수 있습니다. 위쪽 경로에서 상위 폴더 이름을 누르면 바로 이동하며, 현재 폴더 이름이나 빈 공간을 클릭하거나 ⌘L을 눌러 주소를 직접 입력할 수 있습니다. 뒤로·앞으로 버튼과 상위 폴더 메뉴도 사용할 수 있습니다.

02 / TEMPORARY SHELF

임시보관함: 모아 두고, 한 번에 정리하세요.

여러 폴더에 흩어진 파일을 모아 둘 때 사용합니다. 원본을 옮기지 않고 보관 목록에 담은 뒤, 원하는 폴더에 한꺼번에 복사할 수 있습니다.

1. 파일 모으기

파일을 보관함으로 드래그하거나, 파일을 복사한 후 파일 붙여넣기를 누릅니다. 선택 파일의 우클릭 메뉴에서 임시 보관함에 추가도 가능합니다. 폴더와 폴더 링크도 추가할 수 있습니다. 클립보드의 이미지는 분할 창이나 보관함을 클릭하고 ⌘V를 누르면 이미지 파일로 저장됩니다.

2. 저장할 폴더 선택

파일을 받을 창을 클릭하고 목적지 폴더를 엽니다. 강조된 테두리를 확인하세요.

3. 원하는 곳에 복사

현재 폴더에 저장을 누르면 보관된 항목 전체가 선택한 로컬 폴더에 복사됩니다. 개별 항목을 원하는 폴더로 드래그해서 꺼낼 수도 있습니다.

‘보관 목록 지우기’는 원본을 삭제하지 않습니다.

목록만 비웁니다. 임시보관함은 파일의 별도 백업이 아니므로 원본 파일을 지우거나 외장 디스크 연결을 해제하면 해당 파일을 사용할 수 없습니다. 목록은 앱을 다시 실행해도 유지됩니다.

왼쪽 도구 → 플로팅 보관함으로 작은 독립 창을 띄울 수 있습니다. 설정에서 보관함 버튼을 아이콘 + 이름 또는 아이콘만으로 바꿀 수 있습니다. 맥 파인더·윈도우 탐색기 스타일에서는 하단 보관함이 숨겨집니다.

설정에서 임시보관함 사용 여부를 선택하세요. 기본값은 사용이며, 사용 안함을 선택하면 파일 영역이 아래로 확장됩니다. 보관함을 숨겨도 원본 파일은 삭제되지 않습니다.

03 / PREVIEW

열기 전에 내용을 확인하세요.

각 창의 보기 버튼으로 아이콘·목록·열·갤러리 보기를 선택합니다. 이미지·영상·음악·문서는 macOS가 지원하는 썸네일로 표시하며, 지원하지 않는 형식은 해당 파일 아이콘으로 표시합니다.

  • 미리보기 패널: 파일을 선택하고 상단 파일 정보 버튼 또는 … → 미리보기 옵션 → 미리보기 패널을 켭니다.
  • 동영상·음악 재생: 지원하는 미디어 파일의 재생 버튼 또는 우클릭 재생을 사용하면 FileDesk 안에서 재생합니다. MP4·MOV·MP3는 물론 MKV·WebM·AVI도 창 안에서 재생합니다(MKV 등은 재생하면서 변환하므로 변환된 구간까지 이동할 수 있습니다). 재생하지 못하는 파일은 설치된 재생 앱(IINA·VLC 등)으로 엽니다. 네트워크 드라이브(WebDAV 등)에서는 목록을 먼저 파일 종류 아이콘으로 표시하고, 사진과 MP4 등의 미리보기 이미지는 뒤에서 차례로 채웁니다.
  • Quick Look: 파일을 선택하고 스페이스바 또는 훑어보기를 누릅니다. SRT 자막은 타임코드와 본문을 보여 줍니다. 방향키로 다음 파일을 볼 수 있습니다.
  • 폴더 상태: 빈 폴더와 파일이 들어 있는 폴더를 아이콘과 항목 수로 구분합니다.

Quick Look에서 ⌘⌫로 선택 파일을 휴지통에 보내면 다음 파일의 선택과 미리보기가 이어집니다. 마지막 파일을 지우면 이전 파일로 이동하며, 목록이 비면 미리보기가 닫힙니다.

04 / EVERYDAY WORK

복사부터 검색까지, 선택한 창에서.

파일 우클릭과 창의 … 버튼은 같은 작업 메뉴를 엽니다. 작업 전에 테두리가 강조된 창과 선택한 파일을 확인하세요.

파일 작업

새 파일·폴더, 복사·이동·복제, 드래그 앤 드롭, 휴지통으로 이동을 지원합니다. FileDesk 스타일에서는 상단 복사·붙여넣기·이동 버튼을 사용할 수 있습니다. 같은 이름이 있으면 충돌 처리 방법을 확인합니다. 드래그는 Finder와 같습니다. 같은 디스크 안에서는 이동, 다른 디스크로는 복사하며, ⌥를 누르면 복사, ⌘를 누르면 이동합니다. 휴지통으로 이동할 때 확인 창은 기본으로 표시하지 않으며, 파일 메뉴의 휴지통으로 이동 전 확인으로 켤 수 있습니다. 지원되는 로컬 파일 작업은 ⌘Z로 되돌리고 ⇧⌘Z로 다시 실행합니다. 최대 30단계의 기록이 앱 재시작 후에도 유지됩니다.

찾기와 정렬

⌘F로 현재 로컬 패널을 검색합니다. 이름·태그, 여러 검색어와 !제외어를 사용할 수 있습니다. 검색창의 돋보기 메뉴에서 하위 폴더 포함을 선택하면 현재 폴더 아래도 검색합니다. … → 다음으로 정렬에서 이름·수정일·크기·종류와 내림차순을 선택합니다. 폴더를 먼저 모으려면 폴더 먼저 표시를 켜세요.

그룹 사용과 다음으로 그룹화에서 종류·이름·수정일·크기에 따라 파일을 묶어 볼 수 있습니다. 보기 옵션 → 숨김 파일 표시로 숨김 파일을 표시합니다. 연결된 클라우드·FTP/SFTP 창은 원격 목록 탐색과 이름 검색, 업로드·다운로드 중심으로 동작합니다.

05 / BATCH RENAME

바뀔 이름을 먼저 확인하세요.

여러 파일을 선택한 뒤 이름 변경을 누르거나 … → 추가 작업 → 고급 일괄 이름 변경을 엽니다. 기본 이름, 접두어·접미어, 찾기·바꾸기·삭제, 정규식, 번호와 자릿수, 수정일, 대소문자를 조합할 수 있습니다. 자주 쓰는 규칙은 저장했다가 다시 불러옵니다.

파일 하나는 F2로 바로 이름을 편집할 수 있습니다. Mac의 기능 키 설정에 따라 fn을 함께 눌러야 할 수 있습니다.

06 / COLOR & IDENTITY

태그, 폴더 색상, 가운데 이미지.

Finder와 함께 쓰는 색상 태그

파일을 우클릭해 동그란 색상 태그를 누릅니다. 여러 색을 함께 적용할 수 있으며, 선택된 색에는 ✓가 표시됩니다. 여러 파일 중 일부에만 있는 태그는 −로 표시하고, 클릭하면 전체 선택에 적용합니다. 왼쪽 태그 메뉴에서 색상별 파일을 모아 보세요.

Finder 태그와 같은 메타데이터를 사용합니다. Finder에서 바꾼 태그도 FileDesk에 반영됩니다. 파일 시스템과 검색 인덱스의 반영에는 시간이 걸릴 수 있습니다.

색상표로 내 폴더 색 만들기

폴더를 우클릭하고 폴더 색상 → 사용자 지정 색상…을 누릅니다. 색상표 열기…에서 색을 고르고 적용하세요. 기본 8가지 색과 기본 색상 복원도 제공하며 여러 폴더에 함께 적용할 수 있습니다.

폴더 가운데 이미지 넣기

폴더 이미지 → 이미지 파일 선택…에서 ICNS(Mac), ICO(Windows), PNG 등의 이미지를 선택합니다. 복사한 이미지나 아이콘 파일은 이미지 붙여넣기로 추가할 수 있습니다.

폴더의 윤곽은 유지하고 앞면 중앙에 이미지를 배치합니다. 흰색 사각 받침 없이 이미지의 투명 배경을 유지하며, 빈 부분에는 폴더 색이 그대로 보입니다. 은은한 그림자는 이미지 모양을 따릅니다. 삽입 이미지 제거는 가운데 이미지만 없앱니다. 폴더 색상과 이미지는 FileDesk의 표시 설정이며 Finder 태그와는 별개입니다.

즐겨찾기 항목의 우클릭 메뉴에서는 즐겨찾기 아이콘 색상·글자 색상을 따로 지정하고 사용자 즐겨찾기를 제거할 수 있습니다.

07 / APPEARANCE

편안한 색과 익숙한 스타일로.

FileDesk 스타일에서는 왼쪽 메뉴 맨 아래의 설정 → 화면 모양에서 테마와 시스템·라이트·다크 모드를 고릅니다. 아래 버튼을 누르면 실제 테마 화면을 비교할 수 있습니다.

나만의 테마 색상

설정의 사용자 지정 색상에서 macOS 색상표를 엽니다. 선택한 색은 저장되며 라이트·다크 모드의 가독성을 위해 강조색 밝기를 조정합니다. 사이드바 글자는 밝은 화면에서 검정, 어두운 화면에서 흰색으로 유지합니다.

세 가지 파인더 스타일

보기 → 파인더 스타일에서 FileDesk·맥 파인더·윈도우 탐색기 스타일을 선택합니다. 모든 스타일에서 분할과 탭을 사용할 수 있습니다. 상단 FileDesk 도구 막대와 하단 임시보관함은 FileDesk 스타일에서만 표시합니다. 윈도우 탐색기 스타일은 아래에 파일·폴더 수와 남은 용량을 표시합니다.

설정에서 도구 막대를 아이콘 + 이름 또는 아이콘만으로 바꾸고 버튼별 표시 여부를 저장할 수 있습니다. 메뉴 언어는 한국어·영어·일본어·독일어·프랑스어·중국어 간체·번체를 지원합니다.

08 / CONNECTED DRIVES

연결한 드라이브도 현재 창에서.

클라우드 연결

  1. 드라이브를 표시할 패널을 먼저 클릭합니다.
  2. Google Drive·OneDrive·pCloud·Dropbox의 공식 동기화 앱에서 먼저 로그인합니다.
  3. 왼쪽 클라우드 연결에서 찾은 동기화 폴더를 선택합니다. 목록에 없으면 다시 찾기를 누르거나 폴더를 직접 지정합니다.
  4. 폴더를 열면 선택한 메인 패널에 파일과 폴더가 나타납니다. 동기화 상태는 공식 앱에서 관리합니다.

별도 동기화 앱 없이 연결하려면 고급: 직접 로그인… → 계정 추가…에서 서비스를 선택하고 브라우저에서 로그인으로 권한 동의를 완료합니다. 직접 연결한 계정은 왼쪽 메뉴에서 다시 열 수 있습니다.

설정 창은 연결을 관리하는 곳입니다. 파일 탐색, 폴더 이동, 업로드·다운로드는 패널에서 합니다. 계정 정보는 로컬에 암호화해 저장하며 일시적인 연결 오류만으로 계정을 삭제하지 않습니다. 서비스에서 권한을 철회하거나 재인증을 요구하면 다시 로그인해야 합니다.

서버 연결

Dropbox 연결… 버튼으로 Dropbox 브라우저 로그인을 시작할 수도 있습니다. 인증 키 등록 없이 로그인하고 승인하면 선택한 패널에 열립니다. 기본 개인 공간을 지원합니다.

  1. 표시할 패널을 클릭하고 왼쪽 서버 연결을 엽니다.
  2. 프로토콜, 주소, 사용자 이름 등 서버 정보를 입력합니다. SFTP는 암호를 비우면 터미널의 ssh 설정(~/.ssh/config의 호스트 별칭, SSH 에이전트, 키)을 그대로 사용하고, 필요하면 개인 키를 직접 선택할 수도 있습니다.
  3. 연결하면 선택한 패널에서 서버 폴더를 탐색합니다. 주소 프로필을 저장할 수 있으며 암호는 프로필에 저장하지 않습니다.

SMB·WebDAV·NFS·AFP는 macOS가 볼륨으로 연결합니다. FTP·FTPS·SFTP는 원격 목록에서 파일과 폴더를 업로드·다운로드합니다. 전송 중 상태 줄에서 진행률·전송량·남은 시간을 확인하고 취소할 수 있습니다. 여러 항목은 한 번에 병렬로 보내며(설정 → 전송에서 동시 전송 수 조절), 같은 계정 안의 클라우드 복사는 서비스 서버에서 바로 처리합니다. 멈춘 전송은 같은 항목을 다시 보내면 남은 파일만 이어서 보냅니다. SFTP는 등록된 서버 키를 확인합니다. 서버의 삭제는 휴지통이나 실행 취소로 복구할 수 없습니다.

Google 공개 검증 상태

인증 앱은 프로덕션 상태지만 공개 검증은 아직 완료되지 않았습니다. 미확인 앱 안내와 사용자 수 제한이 남을 수 있습니다. OneDrive·pCloud의 실제 연결 가능 여부는 계정·서비스 정책에 따라 확인이 필요합니다. 연결된 클라우드(공식 동기화 앱 폴더, iCloud Drive, 직접 로그인한 계정)와 서버, 실행 중인 공유 서버는 왼쪽 위치에 표시됩니다. 새 연결은 왼쪽 연결의 클라우드 연결·서버 연결·공유 서버·Taildrop에서 설정합니다. 위치의 항목을 오른쪽 클릭하면 이름 변경…으로 표시 이름을 바꿀 수 있어 Google Drive 계정을 여러 개 연결해도 구분하기 쉽고(비워 두면 기본 이름), 연결 해제…로 바로 해제할 수 있습니다. 클라우드·서버의 파일과 공식 앱의 로그인은 그대로 유지됩니다. 클라우드는 서비스별 아이콘으로, NAS는 제조사(예: Synology) 아이콘으로 표시합니다. 두 창 사이에서 클라우드·서버·로컬 항목을 드래그하면 복사됩니다. 서버나 클라우드가 포함되면 이동 대신 복사만 하며, 원본은 그대로 남습니다.

09 / SEND TO YOUR DEVICES

Taildrop으로 내 다른 기기에 보내세요.

Mac에서 선택한 파일을 Tailscale에 연결된 내 다른 기기로 전송합니다. Windows PC로 자료를 보낼 때도 사용할 수 있습니다.

먼저 준비하세요

  • 보내는 Mac과 받는 기기에 Tailscale을 설치하고, 본인 계정으로 로그인해 연결을 켭니다.
  • Tailscale 관리 콘솔의 General 설정에서 Send Files가 켜져 있는지 확인합니다.
  • 현재 Taildrop은 본인 소유의 개인 기기 사이에서 사용합니다. 다른 사용자 소유 기기와 태그가 지정된 기기는 제한됩니다. 설정의 전송 섹션에서 왼쪽 메뉴에 Taildrop과 LocalSend를 각각 표시할지 선택할 수 있습니다.

서비스 준비 조건: Tailscale 공식 Taildrop 안내

FileDesk에서 전송하기

  1. 보낼 파일 또는 폴더를 선택합니다.
  2. 우클릭 Taildrop으로 보내기… 또는 왼쪽 Taildrop을 누릅니다.
  3. 받을 기기 목록에서 온라인 기기를 선택합니다. 필요하면 파일 선택…으로 대상을 다시 고릅니다.
  4. 보내기를 누르고 완료 상태를 확인합니다. 수신 파일은 받는 기기의 Tailscale에서 확인합니다.
폴더 전송과 한글 이름

폴더는 ZIP으로 묶어 보냅니다. 일반 파일과 전송되는 ZIP의 이름은 한글 자모 분리를 줄이도록 조합형 이름으로 정규화합니다. 원본 이름은 바꾸지 않습니다. ZIP 내부 경로와 받는 앱의 처리 방식은 별개입니다.

받을 기기가 없으면 양쪽 연결과 Send Files 설정을 확인한 뒤 새로 고침하세요. FileDesk는 Tailscale이 수신을 허용한 기기만 표시합니다. Taildrop은 FileDesk의 클라우드 계정 연결과 별개의 기능입니다.

AirDrop

왼쪽 AirDrop은 Finder의 AirDrop 화면을 엽니다. 파일·폴더를 선택한 뒤 상단 AirDrop 또는 공유 메뉴를 사용하면 macOS 시스템 전송 창에서 주변 Apple 기기로 보낼 수 있습니다.

10 / ARCHIVES

압축 파일의 내용부터 확인하세요.

파일을 선택하고 압축으로 ZIP 또는 TAR.GZ를 만듭니다. 압축 파일은 내부 목록·검색으로 내용을 확인하고 전체를 해제할 수 있습니다. 한글 ZIP 이름, 앱 내부 링크와 실행 권한, 단일 GZ·BZ2 파일 해제를 지원합니다. 암호화·손상된 파일 등은 형식에 따라 처리되지 않을 수 있습니다.

11 / WORKSPACE & TOOLS

작업 공간

패널 배치와 폴더 위치는 자동 복원됩니다. 왼쪽 현재 배치 저장으로 이름을 붙여 저장하면 자주 쓰는 조합을 다시 열 수 있습니다.

비교와 중복 검색

위치와 즐겨찾기

외장 디스크·설치용 디스크 이미지·네트워크 볼륨 옆 추출 버튼으로 마운트를 해제합니다. 시스템·내장 디스크는 제외합니다. 이동 메뉴에는 기본 위치, 최근 폴더 15개, 상위 폴더·시동 디스크·경로 입력이 있습니다.

일반판의 터미널 열기는 macOS 기본 Terminal을 사용합니다. 다른 터미널 앱 선택은 Pro 전용입니다.

일반판 기능 둘러보기

도구 막대를 원하는 가장자리에

도구 막대가 파일 작업용 시스템 도구 막대와, 직접 등록한 앱·파일·폴더·웹 바로가기를 모은 런처 도구 막대로 나뉩니다. 왼쪽 위 ⠿ 손잡이를 끌어 창의 위·아래·왼쪽·오른쪽에 붙이세요. 손잡이를 클릭해도 위치를 고를 수 있습니다.

도구 막대 왼쪽 위의 ⠿ 손잡이를 끌면 놓을 수 있는 위치가 표시됩니다. 원하는 가장자리에서 놓으세요. 설정 → 도구 막대에서도 두 도구 막대의 위치를 고를 수 있습니다.

왼쪽 메뉴 섹션 접기와 순서 바꾸기

섹션 제목을 클릭하면 접히고, 제목을 끌어 자주 쓰는 섹션을 위로 올릴 수 있습니다. 제목을 우클릭하면 모든 섹션을 한 번에 접거나 펼치고 기본 순서로 되돌립니다.

설정 → 왼쪽 메뉴에서 섹션마다 펼침을 켜거나 끄고, 위·아래 버튼으로 순서를 바꿀 수 있습니다. 바꾼 배치는 모든 창에 함께 적용됩니다.

사이드바에서 설정 열기

설정은 도구 막대의 톱니바퀴 대신 왼쪽 메뉴 맨 아래에서 엽니다(⌘,). 일반·화면 모양·도구 막대·왼쪽 메뉴·임시 보관함·전송으로 나뉜 화면에서 도구 막대 위치와 섹션 순서까지 바꿀 수 있습니다.

왼쪽 메뉴 맨 아래의 설정을 누르거나 ⌘,를 누르세요. 왼쪽 목록에서 범주를 고릅니다. 모두 기본값으로…를 누르면 도구 막대·왼쪽 메뉴·보관함·터미널 설정이 기본값으로 돌아가며, 테마와 등록한 런처는 유지됩니다.

다운로드와 임시보관함

다운로드 폴더를 ‘추가된 날짜’로 정렬하세요. 임시보관함에서 항목을 선택한 뒤 스페이스 바로 훑어보거나 ‘창에서 보기’로 원본 위치를 열 수 있습니다. 파일 이름은 색상이나 단색으로 표시할 수 있습니다.

색상 태그와 목록 정리

체크된 색상을 다시 누르면 이름을 바꾼 색상 태그도 해제됩니다. iCloud의 사용자 지정 회색 태그는 보존됩니다. 다운로드 목록은 첫 행부터 표시되며, 일괄 이름 변경은 큰 시작 번호도 지원합니다.

건너뛴 동기화 충돌 다시 확인하기

이번 동기화에서 건너뛴 충돌은 앱을 다시 열어도 다음 비교에 표시됩니다. 수정 시각은 양쪽 저장소가 공통으로 기록하는 정밀도에 맞춰 비교합니다.

실행 취소와 원격 파일 편집

실행 취소 전에는 해당 경로에 있는 항목이 원래 작업의 대상과 같은지 확인합니다. 원격 파일의 편집 세션은 각각 따로 추적합니다.

디스크 사용량 보기

현재 폴더나 선택한 폴더의 하위 항목 크기를 원형 차트와 표로 보여 줍니다. 파일 크기와 디스크 할당 크기를 따로 표시합니다.

도구 메뉴 또는 우클릭 → 디스크 사용량을 선택하세요. 조각을 누르거나 표의 폴더를 두 번 눌러 내려가고 상위 폴더로 돌아옵니다. 심볼릭 링크와 다른 볼륨은 제외합니다.

스마트 폴더

고급 검색 조건을 사이드바에 저장합니다. 다시 열면 조건과 결과를 복원하고 열어 둔 동안 Spotlight 결과를 자동으로 갱신합니다.

도구 → 고급 검색에서 조건을 입력하고 스마트 폴더 저장을 누르세요. 사이드바의 스마트 폴더에서 다시 열 수 있습니다. 저장 항목 삭제는 검색 조건만 지우며 파일은 그대로 남습니다.

Spotlight 본문 검색

로컬 고급 검색에서 macOS Spotlight 색인을 사용해 큰 문서를 포함한 파일의 본문을 검색합니다.

고급 검색의 본문 검색 방식에서 Spotlight를 선택하세요. 색인되지 않은 위치나 새 파일은 직접 읽기 방식으로 찾을 수 있습니다. 원격 서버는 직접 읽기로 검색합니다.

스프링 로딩 폴더

파일을 끌어 폴더 위에 잠시 올려 두면 그 폴더가 열립니다. 깊은 위치로도 한 번에 옮길 수 있습니다.

파일을 드래그해 목록·아이콘·열 보기나 사이드바의 폴더 위에 0.7초간 유지하세요. 벗어나거나 놓으면 대기가 취소되고, 놓을 수 있는 폴더에서만 열립니다.

Finder 서비스·URL 자동화

Finder 서비스 메뉴와 filedesk:// URL로 FileDesk에서 열기·디스크 사용량·폴더 검색·사진 정보를 실행합니다.

시스템 설정 → 키보드 → 키보드 단축키 → 서비스에서 FileDesk 항목을 켜세요. 단축어 앱에 넣을 URL은 도구 → 자동화 연동에서 현재 폴더 기준으로 복사합니다.

사진 EXIF·메타데이터

촬영일·카메라·렌즈·노출·GPS 정보를 확인하고, 위치·기기 정보를 뺀 PNG 사본을 저장합니다. 원본은 그대로 둡니다.

사진 한 장을 선택한 뒤 도구 메뉴나 우클릭에서 사진 EXIF·메타데이터를 여세요. 메타데이터 제거 사본은 새 파일로만 저장하며 기존 파일을 덮어쓰지 않습니다.

단축키 직접 입력

단축키 설정에서 원하는 키 조합을 눌러 바로 지정합니다. Command·Control 조합과 F1~F20을 지원하고 다른 명령과 겹치면 알려 줍니다.

도구 → 단축키 설정에서 명령을 고르고 ‘클릭한 뒤 단축키를 누르세요’ 버튼을 누른 다음 조합을 누르세요. Esc를 누르면 입력을 취소합니다.

도구막대 웹 바로가기

자주 여는 웹 주소를 도구막대 버튼으로 만들어 기본 브라우저로 엽니다. 로컬 주소는 HTTP, 일반 주소는 HTTPS로 연결합니다.

도구막대 빈 곳을 우클릭해 바로가기 만들기…를 선택하고 이름과 주소를 입력하세요. 버튼을 우클릭하면 이름 변경·주소 편집·제거를 할 수 있습니다.

도구막대를 직접 꾸미기

버튼을 드래그해 순서를 바꾸고 파일·폴더·앱을 도구막대에 드롭해 바로가기로 등록합니다. 우클릭으로 표시 이름을 바꾸거나 제거하며, 원본은 변경하지 않습니다.

버튼을 원하는 위치로 드래그하세요. 파일·폴더·앱을 빈 곳이나 버튼 사이에 드롭하면 런처가 됩니다. 폴더는 활성 파일 창에서, 파일·앱은 macOS를 통해 엽니다. 등록 항목을 우클릭해 이름 변경·제거·기본 순서 복원을 선택합니다.

폴더도 임시 보관함에

파일뿐 아니라 폴더도 드래그·붙여넣기로 보관하고 현재 폴더에 복사합니다. 보관 목록에서 제거해도 원본 폴더와 내부 파일은 유지됩니다.

설정에서 임시보관함을 켠 뒤 폴더를 보관함으로 드래그하세요. 폴더를 클릭해 열고, 현재 폴더에 저장으로 복사합니다. 제거는 보관 참조만 지웁니다. 폴더 내부 파일은 원래 위치에 남습니다.

더 가벼운 미리보기

아이콘 이미지는 표시 크기에 맞춰 저장하고, 썸네일 캐시는 최대 48MiB를 사용합니다. 메모리가 부족해지면 캐시와 숨겨진 미리보기를 해제합니다.

별도 설정 없이 적용됩니다. 캐시 한도는 앱 전체 메모리 한도가 아닙니다. 큰 이미지 편집·여러 창·미디어 재생 중에는 추가 메모리가 필요합니다.

탐색과 선택의 흐름 유지

두 창을 연동해 탐색하고 탭을 고정·복원합니다. 스페이스 미리보기에서 ⌘⌫로 삭제하면 다음 파일로 이어지며, 마지막 파일은 이전 파일로 이동합니다.

두 폴더를 열고 창 연동 탐색을 켜서 같은 하위 경로로 이동합니다. 탭 메뉴에서 고정하거나 닫은 탭을 복원하고, 미리보기 상태에서는 방향키로 다음 파일을 확인합니다.

폴더 동기화와 비교

하위 폴더까지 비교하고 단방향·양방향으로 동기화합니다. 실행할 변경 목록을 먼저 확인하고 제외·삭제 규칙을 저장합니다. 이미지 비교와 외부 비교 앱 연결도 지원합니다.

도구의 폴더 비교·동기화에서 두 폴더와 방향을 고릅니다. 비교 결과의 복사·덮어쓰기·삭제 목록과 제외 규칙을 확인한 뒤 실행하세요. 원격 저장소의 자동 동기화와는 별개입니다.

서버와 전송 관리

S3·Backblaze B2·Rackspace 연결, Dropbox 공유 링크, 원격 편집 변경 감지·업로드와 충돌 확인을 추가했습니다. 전송 대기열 순서·속도 제한·활동 기록을 관리합니다.

서버 연결에서 S3·B2·Rackspace 등 유형과 계정을 설정합니다. 원격 파일은 원격 편집으로 열어야 저장 후 업로드를 감지하며, 충돌하면 확인이 필요합니다. 전송 대기열에서 순서와 속도를 조절합니다.

내게 맞는 작업 환경

임시보관함을 설정에서 켜거나 끄고(기본값: 사용), 단축키를 바꿉니다. 빠른 실행, 사용자 명령, 즐겨찾기 iCloud 동기화와 macOS 기본 터미널 열기를 지원합니다.

설정에서 임시보관함·단축키를 바꾸고 도구에서 빠른 실행·사용자 명령을 엽니다. 사용자 명령은 실행할 프로그램과 인수를 확인한 뒤 저장하고, 즐겨찾기 동기화는 같은 iCloud 계정에서 사용합니다.

기본 앱으로 열기와 정보

더블클릭으로 기본 앱에서 엽니다. 연결된 앱이 없으면 macOS의 앱 선택 절차를 사용합니다. Finder 정보 가져오기에서 파일 정보와 연결 앱을 확인·변경합니다.

파일을 더블클릭하면 macOS 기본 앱으로 엽니다. 우클릭 정보 가져오기에서 Finder의 다음으로 열기를 바꾸고, 같은 형식 전체에 적용하려면 모두 변경을 사용합니다.

파일 정리와 기본 압축

순서 있는 이름 변경 규칙과 날짜·위치 삽입, 앱 잔여 파일 검토, 압축 내부 탐색·미리보기·선택 해제를 제공합니다. 기본 ZIP·TAR.GZ 압축은 일반판 기능입니다.

여러 파일의 이름 변경 규칙을 순서대로 추가하고 결과를 먼저 확인합니다. 압축 만들기에서 ZIP 또는 TAR.GZ를 선택하고, 압축 내부에서는 원하는 항목을 선택해 해제합니다. 앱 정리는 제거할 잔여 파일을 검토한 뒤 실행합니다.

필요한 파일만 빠르게 찾기

파일 내용·크기·날짜 등 조건으로 검색하고 원격 폴더도 재귀 탐색합니다. 빠른 선택에서 이름·확장자 등 조건에 맞는 파일을 선택하거나 제외합니다.

내용 검색에서 검색어와 크기·날짜 조건을 정하고 검색 범위를 선택합니다. 빠른 선택에서는 이름·확장자 조건으로 현재 목록의 선택을 추가하거나 제외합니다.

파일 창에서 Git 작업까지

변경 상태를 확인하고 파일 추가·커밋·푸시·풀을 실행합니다. 저장소 작업을 파일 탐색 흐름 안에서 이어갑니다.

Git 저장소 폴더에서 도구의 Git 창을 열고 변경 파일을 확인합니다. 필요한 파일만 추가하고 메시지를 작성해 커밋하며, 푸시·풀에는 해당 원격 저장소의 접근 권한이 필요합니다.
